What is loaded: repo metadata, full file tree at one commit, the latest N×100 commits, contributors, issues and pull requests, releases, languages. Per‑file churn is not loaded (GitHub's commit list has no file paths), so commits has no path column.

Bookmarklet — drag to your bar, click on any GitHub page: gitsql this repo

Open source, single HTML file, no server. Source and issues: github.com/ejoliet/gitsql.
