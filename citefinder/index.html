        Needs Node 20 or later. Tokens come from environment variables: ADS_TOKEN, GITHUB_TOKEN, S2_API_KEY. Writes ./CITATION.cff. The terminal version ships with v0.1.0.

        Requests go only to GitHub, ADS, DataCite, Crossref, doi.org, ORCID and Semantic Scholar. Format follows GitHub's CITATION file guide. Source, MIT.
