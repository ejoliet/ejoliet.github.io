How it works: one GitHub API call for the tree, then each candidate file is fetched from jsDelivr's GitHub mirror and matched against ~40 language-specific patterns (Python, Node, Go, Rust, Java, Ruby, PHP, .NET, shell, Dockerfile, Compose, GitHub Actions, Spring, Helm). No AI. False positives are possible; every finding links to its line.
