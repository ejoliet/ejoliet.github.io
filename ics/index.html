Drop an .ics file here or click to choose one — parsed in your browser, stored only in this browser's localStorage.
The URL is fetched directly by your browser. The server must send CORS headers (Access-Control-Allow-Origin) or the fetch will fail — no proxy is used.

Embed & export

1 — Iframe with data in the URL fragment

Host this file yourself; the calendar data travels in the #fragment, which browsers never send to any server. Best for calendars under ~50 KB.

2 — Standalone HTML file

A self-contained read-only viewer with the events baked in. Host it anywhere, or open it from disk. No storage, no requests.

3 — Inline srcdoc iframe (no hosting at all)

Paste this straight into any HTML page. The whole viewer and its data live inside the attribute. Bulky, but fully self-contained.

Single file, no dependencies, no analytics. Recurring events: DAILY / WEEKLY (BYDAY) / MONTHLY / YEARLY with INTERVAL, COUNT, UNTIL and EXDATE. Times with a TZID are shown as wall-clock local time.
